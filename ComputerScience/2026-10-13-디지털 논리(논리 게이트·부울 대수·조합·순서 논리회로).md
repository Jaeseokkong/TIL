# 🔌 디지털 논리 - 논리 게이트, 부울 대수, 조합/순서 논리회로

컴퓨터 하드웨어는 결국 0과 1만 다루는 **논리 게이트의 조합**으로 만들어집니다. 그 기본 단위부터 정리합니다.

---

## 1️⃣ 논리 게이트 (Logic Gates)

| 게이트 | 기호 | 동작 |
|--------|------|------|
| AND | `A·B` | 입력이 모두 1일 때만 출력 1 |
| OR | `A+B` | 입력 중 하나라도 1이면 출력 1 |
| NOT | `A'` | 입력을 반전 |
| NAND | `(A·B)'` | AND의 결과를 반전 |
| NOR | `(A+B)'` | OR의 결과를 반전 |
| XOR | `A⊕B` | 입력이 서로 다를 때만 출력 1 |
| XNOR | `(A⊕B)'` | 입력이 서로 같을 때만 출력 1 |

### 🔹 범용 게이트 - NAND, NOR

- NAND와 NOR는 **이 게이트 하나만으로 AND, OR, NOT 등 다른 모든 게이트를 구현**할 수 있어 "범용 게이트"라 불림
- 실제 반도체 제조 공정에서 NAND 게이트의 내부 구조가 단순해, CPU 등 실제 회로에서 기본 빌딩 블록으로 널리 사용됨

## 2️⃣ 부울 대수 (Boolean Algebra)

논리 게이트의 동작을 **수식으로 표현하고 단순화**하기 위한 대수 체계입니다.

### 🔹 기본 법칙

- 교환법칙: `A + B = B + A`, `A · B = B · A`
- 결합법칙: `(A + B) + C = A + (B + C)`
- 분배법칙: `A · (B + C) = A·B + A·C`

### 🔹 드모르간의 법칙 (De Morgan's Law)

```
(A · B)' = A' + B'
(A + B)' = A' · B'
```

- "AND의 부정은 OR로, OR의 부정은 AND로 바뀌면서 각 입력도 반전된다"는 법칙
- NAND/NOR만으로 다른 게이트를 구현할 때, 그리고 복잡한 논리식을 단순화할 때 핵심적으로 사용됨

### 🔹 회로 단순화의 의미

- 같은 동작을 하는 회로라도 게이트 수를 줄이면 **제조 비용과 신호 지연 시간**을 줄일 수 있음
- 부울 대수로 논리식을 정리한 뒤 회로를 설계하는 것이 실제 하드웨어 설계의 기본 과정
