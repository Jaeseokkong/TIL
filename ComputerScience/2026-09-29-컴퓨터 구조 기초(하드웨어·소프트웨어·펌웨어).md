# 💻 컴퓨터 구조 기초 - 하드웨어, 소프트웨어, 펌웨어

컴퓨터를 구성하는 요소를 큰 틀에서 **하드웨어 / 소프트웨어 / 펌웨어** 세 가지로 나눠 정리합니다.

---

## 1️⃣ 하드웨어

### 🔹 중앙처리장치 (CPU)

| 구성 요소 | 역할 |
|-----------|------|
| 제어장치 (CU) | 명령어를 해석하고, 각 장치에 제어 신호를 보내 동작을 지시. 명령어 인출(Fetch) → 해독(Decode) → 실행(Execute) 사이클을 관리 |
| 연산장치 (ALU) | 실제 산술 연산(덧셈, 뺄셈 등)과 논리 연산(AND, OR, NOT 등)을 수행 |
| 레지스터 | CPU 내부의 초고속 임시 저장 공간. 메모리보다 훨씬 빠르지만 용량은 매우 작음 (프로그램 카운터(PC), 명령어 레지스터(IR), 누산기(ACC), 범용 레지스터 등) |
| CPU 내부 버스 | 제어장치·연산장치·레지스터 사이에서 데이터를 주고받는 통로. 데이터 버스 / 주소 버스 / 제어 버스로 구성 |

- 명령어 실행 흐름: 제어장치가 메모리에서 명령어를 **인출**하고 **해독**한 뒤, 연산이 필요하면 연산장치에 전달해 **실행**하고 결과를 레지스터/메모리에 저장

### 🔹 기억장치

- **주기억장치**: CPU가 직접 접근 가능한 메모리
  - RAM: 휘발성, 실행 중인 프로그램/데이터를 저장 (전원이 꺼지면 사라짐)
  - ROM: 비휘발성, 부팅에 필요한 정보 등을 저장
- **보조기억장치**: HDD, SSD처럼 전원이 꺼져도 데이터가 유지되는 대용량 저장장치. CPU가 직접 접근할 수 없어 주기억장치(RAM)로 옮겨진 뒤에야 처리 가능

### 🔹 입출력장치

- **입력장치**: 키보드, 마우스, 스캐너 등 외부 데이터를 컴퓨터로 전달
- **출력장치**: 모니터, 프린터, 스피커 등 처리 결과를 사람이 인식 가능한 형태로 변환
