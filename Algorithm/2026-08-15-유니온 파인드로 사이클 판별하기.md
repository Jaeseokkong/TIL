# 🔗 유니온 파인드로 사이클 판별하기

그래프에 간선을 하나씩 추가하면서 **사이클이 생기는지 여부**를 빠르게 판별할 때 사용하는 자료구조입니다.

---

## 1️⃣ 핵심 연산

- `find(x)` - x가 속한 집합의 대표(루트) 노드를 찾음
- `union(x, y)` - x와 y가 속한 두 집합을 하나로 합침
- 간선 `(u, v)`를 추가하기 전, `find(u) === find(v)`이면 이미 같은 집합 → **사이클 발생**

---

## 2️⃣ 풀이 코드 (경로 압축 적용)

```js
class UnionFind {
  constructor(n) {
    this.parent = Array.from({ length: n }, (_, i) => i);
  }

  find(x) {
    if (this.parent[x] !== x) {
      this.parent[x] = this.find(this.parent[x]); // 경로 압축
    }
    return this.parent[x];
  }

  union(x, y) {
    const rootX = this.find(x), rootY = this.find(y);
    if (rootX === rootY) return false; // 이미 연결됨 → 사이클
    this.parent[rootX] = rootY;
    return true;
  }
}
```

- 경로 압축을 적용하면 `find` 연산이 사실상 O(1)에 가까워짐

---

## ✍️ 한 줄 정리

> **유니온 파인드는 간선을 추가하기 전 두 노드가 이미 같은 집합인지 확인하는 방식으로 사이클을 O(거의 1)에 판별한다.**
