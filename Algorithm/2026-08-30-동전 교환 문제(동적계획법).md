# 🪙 동전 교환 문제 (동적계획법)

정해진 동전 종류로 특정 금액을 만들 때 **필요한 최소 동전 개수**를 구하는 대표적인 DP 문제입니다. (그리디로는 풀리지 않는 경우가 있음)

---

## 1️⃣ 문제 접근

- `dp[i]` = 금액 i를 만드는 데 필요한 최소 동전 개수
- `dp[i] = min(dp[i - coin] + 1)` (모든 coin에 대해, i - coin >= 0일 때)
- 동전 단위가 배수 관계가 아니면 그리디로는 최적해를 보장할 수 없어 DP가 필요

---

## 2️⃣ 풀이 코드

```js
function coinChange(coins, amount) {
  const dp = Array(amount + 1).fill(Infinity);
  dp[0] = 0;

  for (let i = 1; i <= amount; i++) {
    for (const coin of coins) {
      if (i - coin >= 0) {
        dp[i] = Math.min(dp[i], dp[i - coin] + 1);
      }
    }
  }

  return dp[amount] === Infinity ? -1 : dp[amount];
}

coinChange([1, 3, 4], 6); // 2 (3 + 3)
```

---

## ✍️ 한 줄 정리

> **동전 교환 문제는 그리디로는 항상 최적해를 보장할 수 없어, 작은 금액부터 최소 개수를 누적해나가는 DP로 풀어야 한다.**
