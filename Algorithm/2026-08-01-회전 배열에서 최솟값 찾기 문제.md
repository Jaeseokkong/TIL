# 🔄 회전된 정렬 배열에서 최솟값 찾기

오름차순으로 정렬된 배열을 임의의 지점에서 회전시켰을 때, 최솟값(회전 지점)을 O(log n)에 찾는 문제입니다.

---

## 1️⃣ 문제 접근

- 이진 탐색을 응용: `mid` 값과 `right` 값을 비교
- `nums[mid] > nums[right]` → 최솟값은 mid보다 오른쪽에 있음
- `nums[mid] <= nums[right]` → 최솟값은 mid를 포함해 왼쪽에 있음

---

## 2️⃣ 풀이 코드

```js
function findMin(nums) {
  let left = 0, right = nums.length - 1;

  while (left < right) {
    const mid = Math.floor((left + right) / 2);
    if (nums[mid] > nums[right]) {
      left = mid + 1;
    } else {
      right = mid;
    }
  }

  return nums[left];
}

findMin([4, 5, 6, 7, 0, 1, 2]); // 0
```

---

## ✍️ 한 줄 정리

> **정렬된 배열이 회전되어 있어도, mid와 right 값을 비교하면 이진 탐색으로 최솟값을 찾을 수 있다.**
