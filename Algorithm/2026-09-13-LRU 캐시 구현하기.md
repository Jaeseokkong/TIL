# 🗂️ LRU 캐시 구현하기

캐시 공간이 가득 찼을 때 **가장 오랫동안 사용되지 않은 항목**부터 제거하는 캐시 교체 전략입니다.

---

## 1️⃣ 문제 접근

- `get`/`put` 모두 O(1)에 처리하려면 **Map + 사용 순서 유지**가 핵심
- JS의 `Map`은 삽입 순서를 기억하므로, 접근할 때마다 항목을 삭제 후 다시 넣으면 "가장 최근 사용"을 맨 뒤로 유지 가능

---

## 2️⃣ 풀이 코드

```js
class LRUCache {
  constructor(capacity) {
    this.capacity = capacity;
    this.cache = new Map();
  }

  get(key) {
    if (!this.cache.has(key)) return -1;
    const value = this.cache.get(key);
    this.cache.delete(key);
    this.cache.set(key, value); // 맨 뒤로 이동 = 가장 최근 사용
    return value;
  }

  put(key, value) {
    if (this.cache.has(key)) this.cache.delete(key);
    else if (this.cache.size >= this.capacity) {
      const oldestKey = this.cache.keys().next().value;
      this.cache.delete(oldestKey); // 가장 오래된 항목 제거
    }
    this.cache.set(key, value);
  }
}
```

---

## ✍️ 한 줄 정리

> **LRU 캐시는 Map의 삽입 순서를 활용해 접근할 때마다 항목을 맨 뒤로 옮기는 방식으로, get/put 모두 O(1)에 처리하면서 가장 오래된 항목부터 제거할 수 있다.**
