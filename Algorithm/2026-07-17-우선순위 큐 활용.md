# 📶 우선순위 큐(Priority Queue) 활용

일반 큐와 달리 **우선순위가 높은 요소가 먼저 나오는 자료구조**로,
내부적으로 힙(Heap)을 이용해 삽입/삭제를 O(log n)에 처리합니다.

---

## 1️⃣ 언제 사용하나

- 다익스트라 최단 경로 - 방문하지 않은 노드 중 최단 거리 노드를 빠르게 꺼낼 때
- K번째 최소/최대값 찾기
- 작업 스케줄링 - 우선순위가 높은 작업부터 처리

### 🔹 힙과의 관계

| 구조 | 설명 |
|------|------|
| Min-Heap | 가장 작은 값이 루트 → 오름차순 우선순위 큐 |
| Max-Heap | 가장 큰 값이 루트 → 내림차순 우선순위 큐 |

---

## 2️⃣ 예시 - JS 배열로 흉내낸 우선순위 큐

JS에는 내장 우선순위 큐가 없어 배열 정렬 또는 힙 클래스를 직접 구현합니다.

```js
class MinPriorityQueue {
  #items = [];

  enqueue(value, priority) {
    this.#items.push({ value, priority });
    this.#items.sort((a, b) => a.priority - b.priority);
  }

  dequeue() {
    return this.#items.shift();
  }
}

const pq = new MinPriorityQueue();
pq.enqueue("작업A", 3);
pq.enqueue("작업B", 1);
pq.dequeue(); // { value: "작업B", priority: 1 }
```

⚠️ 배열 정렬 방식은 O(n log n)이라 데이터가 많다면 실제 힙 구현이 필요합니다.

---

## ✍️ 한 줄 정리

> **우선순위 큐는 힙을 기반으로 우선순위가 가장 높은 요소를 O(log n)에 꺼낼 수 있는 자료구조다.**
