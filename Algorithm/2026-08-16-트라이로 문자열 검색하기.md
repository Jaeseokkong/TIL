# 🌳 트라이(Trie)로 문자열 검색하기

여러 단어의 **공통 접두사(prefix)를 트리 구조로 공유**해, 문자열 검색과 자동완성을 빠르게 처리하는 자료구조입니다.

---

## 1️⃣ 핵심 개념

- 각 노드는 알파벳 하나를 나타내고, 자식 노드로 다음 글자를 연결
- 단어의 끝 지점에는 `isEnd` 표시를 둠
- 검색/삽입 모두 **단어 길이에 비례한 O(L)** 시간에 처리 가능

---

## 2️⃣ 풀이 코드

```js
class TrieNode {
  children = new Map();
  isEnd = false;
}

class Trie {
  root = new TrieNode();

  insert(word) {
    let node = this.root;
    for (const ch of word) {
      if (!node.children.has(ch)) node.children.set(ch, new TrieNode());
      node = node.children.get(ch);
    }
    node.isEnd = true;
  }

  search(word) {
    let node = this.root;
    for (const ch of word) {
      if (!node.children.has(ch)) return false;
      node = node.children.get(ch);
    }
    return node.isEnd;
  }
}
```

---

## ✍️ 한 줄 정리

> **트라이는 공통 접두사를 공유하는 트리 구조로, 단어 길이에만 비례하는 시간에 검색·자동완성을 처리할 수 있다.**
