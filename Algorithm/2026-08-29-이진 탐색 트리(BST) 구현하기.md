# 🌲 이진 탐색 트리(BST) 구현하기

각 노드마다 "왼쪽 서브트리는 더 작은 값, 오른쪽 서브트리는 더 큰 값"이라는 규칙을 유지하는 트리 자료구조입니다.

---

## 1️⃣ 핵심 연산

- `insert`: 규칙에 따라 왼쪽/오른쪽으로 내려가며 삽입할 위치를 찾음
- `search`: 찾는 값과 현재 노드를 비교해 왼쪽/오른쪽으로만 이동 → 평균 O(log n)
- 트리가 한쪽으로 치우치면(편향 트리) 최악의 경우 O(n)까지 느려질 수 있음

---

## 2️⃣ 풀이 코드

```js
class TreeNode {
  constructor(value) {
    this.value = value;
    this.left = null;
    this.right = null;
  }
}

class BST {
  root = null;

  insert(value) {
    const newNode = new TreeNode(value);
    if (!this.root) { this.root = newNode; return; }

    let current = this.root;
    while (true) {
      if (value < current.value) {
        if (!current.left) { current.left = newNode; return; }
        current = current.left;
      } else {
        if (!current.right) { current.right = newNode; return; }
        current = current.right;
      }
    }
  }

  search(value) {
    let current = this.root;
    while (current) {
      if (value === current.value) return true;
      current = value < current.value ? current.left : current.right;
    }
    return false;
  }
}
```

---

## ✍️ 한 줄 정리

> **BST는 왼쪽은 작은 값, 오른쪽은 큰 값이라는 규칙으로 평균 O(log n) 탐색을 제공하지만, 트리가 한쪽으로 치우치면 성능이 O(n)까지 떨어질 수 있다.**
