# 🚗 다익스트라(Dijkstra) 최단 경로 알고리즘

음수 가중치가 없는 그래프에서, **한 출발점으로부터 모든 정점까지의 최단 거리**를 구하는 알고리즘입니다.

---

## 1️⃣ 문제 접근

- 출발점의 거리는 0, 나머지는 무한대로 초기화
- 아직 확정되지 않은 정점 중 **거리가 가장 짧은 정점**을 우선순위 큐에서 꺼내 확정
- 확정된 정점을 거쳐 갈 때 더 짧아지는 경로가 있으면 인접 정점의 거리를 갱신(완화, relaxation)

---

## 2️⃣ 풀이 코드 (우선순위 큐 활용)

```js
function dijkstra(n, graph, start) {
  const dist = Array(n).fill(Infinity);
  dist[start] = 0;
  const pq = [[0, start]]; // [거리, 노드]

  while (pq.length) {
    pq.sort((a, b) => a[0] - b[0]);
    const [d, node] = pq.shift();
    if (d > dist[node]) continue;

    for (const [next, weight] of graph[node]) {
      const newDist = d + weight;
      if (newDist < dist[next]) {
        dist[next] = newDist;
        pq.push([newDist, next]);
      }
    }
  }

  return dist;
}
```

⚠️ 실제 서비스 코드에서는 배열 정렬 대신 실제 힙(우선순위 큐)을 써야 대규모 그래프에서도 성능이 유지됨

---

## ✍️ 한 줄 정리

> **다익스트라는 아직 확정되지 않은 정점 중 거리가 가장 짧은 곳부터 확정해나가는 그리디 방식으로, 음수 가중치가 없는 그래프의 최단 경로를 구한다.**
