# 🔙 백트래킹 (Backtracking)

가능한 모든 경우를 탐색하되, **조건에 맞지 않는 경로는 즉시 포기(가지치기)** 하며
불필요한 탐색을 줄이는 알고리즘 기법입니다.

---

## 1️⃣ 핵심 아이디어

- DFS 기반으로 해를 하나씩 구성해 나감
- 현재 상태가 조건을 만족하지 못하면 더 진행하지 않고 **되돌아감(backtrack)**
- 완전 탐색보다 훨씬 적은 경우의 수만 탐색

### 🔹 완전 탐색 vs 백트래킹

| 구분 | 완전 탐색 | 백트래킹 |
|------|-----------|----------|
| 탐색 방식 | 모든 경우 끝까지 확인 | 가능성 없는 경로는 조기 중단 |
| 성능 | 느림 | 상대적으로 빠름 |

---

## 2️⃣ 예시 - N-Queen 문제 (가지치기)

```js
function solveNQueens(n) {
  const cols = new Set();
  const diag1 = new Set();
  const diag2 = new Set();
  let count = 0;

  function backtrack(row) {
    if (row === n) {
      count++;
      return;
    }
    for (let col = 0; col < n; col++) {
      if (cols.has(col) || diag1.has(row - col) || diag2.has(row + col)) continue;

      cols.add(col); diag1.add(row - col); diag2.add(row + col);
      backtrack(row + 1);
      cols.delete(col); diag1.delete(row - col); diag2.delete(row + col);
    }
  }

  backtrack(0);
  return count;
}
```

- 퀸을 놓을 때마다 충돌 조건을 확인하고, 충돌 시 해당 분기는 더 탐색하지 않음

---

## ✍️ 한 줄 정리

> **백트래킹은 DFS로 해를 구성하며, 조건에 어긋나는 순간 가지를 쳐내 불필요한 탐색을 줄이는 기법이다.**
