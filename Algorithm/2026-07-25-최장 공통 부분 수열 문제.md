# 🧬 최장 공통 부분 수열 (LCS) 문제

두 문자열에서 **순서를 유지하며 공통으로 나타나는 가장 긴 부분 수열**의 길이를 구하는 대표적인 DP 문제입니다.

---

## 1️⃣ 문제 접근

- `dp[i][j]` = `text1`의 앞 i글자와 `text2`의 앞 j글자 사이의 LCS 길이
- 마지막 글자가 같으면 `dp[i-1][j-1] + 1`
- 다르면 `max(dp[i-1][j], dp[i][j-1])`

---

## 2️⃣ 풀이 코드

```js
function longestCommonSubsequence(text1, text2) {
  const m = text1.length, n = text2.length;
  const dp = Array.from({ length: m + 1 }, () => Array(n + 1).fill(0));

  for (let i = 1; i <= m; i++) {
    for (let j = 1; j <= n; j++) {
      dp[i][j] = text1[i - 1] === text2[j - 1]
        ? dp[i - 1][j - 1] + 1
        : Math.max(dp[i - 1][j], dp[i][j - 1]);
    }
  }

  return dp[m][n];
}

longestCommonSubsequence("abcde", "ace"); // 3
```

---

## ✍️ 한 줄 정리

> **LCS는 2차원 DP 테이블에 "같으면 대각선+1, 다르면 max"를 채워나가며 구하는 문제다.**
