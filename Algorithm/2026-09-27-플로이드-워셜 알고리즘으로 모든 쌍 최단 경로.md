# 🗺️ 플로이드-워셜(Floyd-Warshall) 알고리즘으로 모든 쌍 최단 경로

다익스트라가 "한 출발점"에서의 최단 경로를 구한다면, 플로이드-워셜은 **모든 정점 쌍 사이의 최단 경로**를 한 번에 구합니다.

---

## 1️⃣ 문제 접근

- `dist[i][j]` = i에서 j까지의 최단 거리 (초기값: 직접 연결된 간선 가중치, 없으면 무한대)
- 모든 정점 k를 **경유지**로 하나씩 고려하며, `dist[i][j] > dist[i][k] + dist[k][j]`면 갱신
- 음수 가중치가 있어도 동작 가능(음수 사이클만 없다면)하다는 점이 다익스트라와의 차이

---

## 2️⃣ 풀이 코드

```js
function floydWarshall(n, dist) {
  for (let k = 0; k < n; k++) {
    for (let i = 0; i < n; i++) {
      for (let j = 0; j < n; j++) {
        if (dist[i][k] + dist[k][j] < dist[i][j]) {
          dist[i][j] = dist[i][k] + dist[k][j];
        }
      }
    }
  }
  return dist;
}
```

⚠️ 시간복잡도가 O(n³)이라 정점 수가 수백 개를 넘어가면 느려질 수 있음 - 정점 수가 많고 출발점이 하나뿐이라면 다익스트라가 더 적합

---

## ✍️ 한 줄 정리

> **플로이드-워셜은 모든 정점을 경유지로 순회하며 거리를 갱신해, 모든 정점 쌍의 최단 경로를 O(n³)에 한 번에 구하는 알고리즘이다.**
