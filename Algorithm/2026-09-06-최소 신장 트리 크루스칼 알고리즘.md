# 🌳 최소 신장 트리 - 크루스칼(Kruskal) 알고리즘

그래프의 모든 정점을 연결하면서 **간선 가중치의 합이 최소가 되는 트리**를 구하는 알고리즘입니다.

---

## 1️⃣ 문제 접근

1. 모든 간선을 가중치 오름차순으로 정렬
2. 가중치가 작은 간선부터 순서대로 확인
3. 두 정점이 **이미 같은 집합(사이클)이 아니라면** 간선을 선택 (유니온 파인드로 판별)
4. 정점 수 - 1개의 간선을 선택하면 종료

---

## 2️⃣ 풀이 코드 (유니온 파인드 활용)

```js
function kruskal(n, edges) {
  edges.sort((a, b) => a.weight - b.weight);
  const parent = Array.from({ length: n }, (_, i) => i);

  function find(x) {
    if (parent[x] !== x) parent[x] = find(parent[x]);
    return parent[x];
  }

  let totalWeight = 0, count = 0;
  for (const { from, to, weight } of edges) {
    const rootA = find(from), rootB = find(to);
    if (rootA !== rootB) {
      parent[rootA] = rootB;
      totalWeight += weight;
      count++;
    }
  }

  return count === n - 1 ? totalWeight : -1; // 모든 정점이 연결되지 않으면 -1
}
```

---

## ✍️ 한 줄 정리

> **크루스칼 알고리즘은 간선을 가중치 순으로 정렬해 사이클을 만들지 않는 선에서 그리디하게 선택해나가며 최소 신장 트리를 구한다.**
