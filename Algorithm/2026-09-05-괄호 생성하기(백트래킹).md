# 🔣 괄호 생성하기 (백트래킹)

n쌍의 괄호로 만들 수 있는 **모든 유효한 조합**을 생성하는 문제입니다.

---

## 1️⃣ 문제 접근

- 여는 괄호 `(`는 개수 제한(n) 내에서 언제든 추가 가능
- 닫는 괄호 `)`는 **이미 사용한 여는 괄호 개수보다 적을 때만** 추가 가능 (그래야 짝이 깨지지 않음)
- 두 조건을 만족하지 않는 분기는 더 진행하지 않고 가지치기

---

## 2️⃣ 풀이 코드

```js
function generateParenthesis(n) {
  const result = [];

  function backtrack(current, open, close) {
    if (current.length === n * 2) {
      result.push(current);
      return;
    }
    if (open < n) backtrack(current + "(", open + 1, close);
    if (close < open) backtrack(current + ")", open, close + 1);
  }

  backtrack("", 0, 0);
  return result;
}

generateParenthesis(3);
// ["((()))","(()())","(())()","()(())","()()()"]
```

---

## ✍️ 한 줄 정리

> **괄호 생성은 "닫는 괄호는 연 괄호 수보다 많을 수 없다"는 조건으로 가지치기하는 백트래킹 문제다.**
