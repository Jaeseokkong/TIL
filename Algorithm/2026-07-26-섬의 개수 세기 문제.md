# 🏝️ 섬의 개수 세기 문제

2차원 격자에서 물(0)과 땅(1)이 주어질 때, 상하좌우로 연결된 땅 덩어리(섬)의 개수를 세는 문제입니다.

---

## 1️⃣ 문제 접근

- 아직 방문하지 않은 땅(1)을 발견하면 섬 개수 +1
- 그 지점에서 BFS/DFS로 연결된 모든 땅을 방문 처리
- 격자 전체를 순회하며 위 과정을 반복

---

## 2️⃣ 풀이 코드 (BFS)

```js
function numIslands(grid) {
  const rows = grid.length, cols = grid[0].length;
  let count = 0;

  function bfs(r, c) {
    const queue = [[r, c]];
    grid[r][c] = "0";

    while (queue.length) {
      const [y, x] = queue.shift();
      for (const [dy, dx] of [[1,0],[-1,0],[0,1],[0,-1]]) {
        const ny = y + dy, nx = x + dx;
        if (ny >= 0 && ny < rows && nx >= 0 && nx < cols && grid[ny][nx] === "1") {
          grid[ny][nx] = "0";
          queue.push([ny, nx]);
        }
      }
    }
  }

  for (let r = 0; r < rows; r++) {
    for (let c = 0; c < cols; c++) {
      if (grid[r][c] === "1") {
        count++;
        bfs(r, c);
      }
    }
  }

  return count;
}
```

---

## ✍️ 한 줄 정리

> **섬 개수 세기는 격자 순회 중 방문하지 않은 땅을 만날 때마다 BFS/DFS로 연결 요소를 모두 지워나가는 문제다.**
