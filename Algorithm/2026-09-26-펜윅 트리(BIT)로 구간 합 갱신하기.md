# 🌳 펜윅 트리(Fenwick Tree, BIT)로 구간 합 갱신하기

값이 계속 바뀌는 배열에서 **구간 합 조회와 특정 값 갱신을 모두 O(log n)**에 처리하는 자료구조입니다.

---

## 1️⃣ 왜 필요한가

- 누적합 배열(Prefix Sum)은 조회는 O(1)이지만, 값 하나만 바뀌어도 **전체를 다시 계산**해야 함(O(n))
- 펜윅 트리는 값 갱신과 구간 합 조회 **둘 다** O(log n)으로 처리 가능해, 값이 자주 바뀌는 상황에 적합
- 비트 연산(`i & -i`)으로 각 노드가 관리하는 구간을 결정하는 것이 핵심

---

## 2️⃣ 풀이 코드

```js
class FenwickTree {
  constructor(n) {
    this.tree = new Array(n + 1).fill(0);
  }

  update(i, diff) {
    for (; i < this.tree.length; i += i & -i) {
      this.tree[i] += diff;
    }
  }

  query(i) {
    let sum = 0;
    for (; i > 0; i -= i & -i) {
      sum += this.tree[i];
    }
    return sum;
  }

  rangeSum(l, r) {
    return this.query(r) - this.query(l - 1);
  }
}
```

- `i & -i`는 i의 최하위 비트만 남기는 연산으로, 각 인덱스가 담당하는 구간의 크기를 결정함

---

## ✍️ 한 줄 정리

> **펜윅 트리는 비트 연산으로 구간을 나눠 관리해, 값이 자주 바뀌는 배열에서도 구간 합 조회와 갱신을 모두 O(log n)에 처리할 수 있다.**
