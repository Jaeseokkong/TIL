# 📋 위상 정렬(Topological Sort)로 작업 순서 정하기

"A를 끝내야 B를 시작할 수 있다"처럼 **선행 관계가 있는 작업들의 실행 순서**를 정하는 문제입니다.

---

## 1️⃣ 문제 접근

- 그래프에서 각 노드의 **진입 차수(in-degree)**를 계산
- 진입 차수가 0인 노드(선행 작업이 없는 작업)부터 큐에 넣고 처리
- 처리할 때마다 연결된 노드의 진입 차수를 1씩 감소, 0이 되면 큐에 추가

---

## 2️⃣ 풀이 코드 (Kahn's Algorithm)

```js
function topologicalSort(numTasks, edges) {
  const graph = Array.from({ length: numTasks }, () => []);
  const indegree = Array(numTasks).fill(0);

  for (const [from, to] of edges) {
    graph[from].push(to);
    indegree[to]++;
  }

  const queue = [];
  for (let i = 0; i < numTasks; i++) if (indegree[i] === 0) queue.push(i);

  const order = [];
  while (queue.length) {
    const cur = queue.shift();
    order.push(cur);
    for (const next of graph[cur]) {
      if (--indegree[next] === 0) queue.push(next);
    }
  }

  return order.length === numTasks ? order : []; // 사이클 있으면 빈 배열
}
```

---

## ✍️ 한 줄 정리

> **위상 정렬은 진입 차수가 0인 노드부터 순서대로 제거해 나가며 선행 관계를 만족하는 순서를 구하는 방법이다.**
