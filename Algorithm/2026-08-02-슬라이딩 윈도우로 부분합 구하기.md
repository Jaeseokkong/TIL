# 🪟 슬라이딩 윈도우로 부분합 구하기

크기가 고정된 부분 배열의 합/최댓값 등을 구할 때, 매번 처음부터 다시 계산하지 않고
**윈도우를 한 칸씩 이동시키며 누적값만 갱신**하는 기법입니다.

---

## 1️⃣ 문제 접근

- 크기 k인 윈도우의 합을 먼저 구함
- 윈도우를 오른쪽으로 한 칸 옮길 때 `+새로 들어온 값 - 빠져나간 값`으로 O(1) 갱신
- 전체 O(n²) → O(n)으로 개선

---

## 2️⃣ 풀이 코드

```js
function maxSubarraySum(nums, k) {
  let windowSum = 0;
  for (let i = 0; i < k; i++) windowSum += nums[i];

  let maxSum = windowSum;

  for (let i = k; i < nums.length; i++) {
    windowSum += nums[i] - nums[i - k];
    maxSum = Math.max(maxSum, windowSum);
  }

  return maxSum;
}

maxSubarraySum([2, 1, 5, 1, 3, 2], 3); // 9
```

---

## ✍️ 한 줄 정리

> **슬라이딩 윈도우는 겹치는 구간을 다시 계산하지 않고 차분만 갱신해 O(n)으로 부분 배열 문제를 푸는 기법이다.**
