# ➕ 두 수의 합 문제 (Two Sum)

정수 배열에서 두 수를 더해 특정 target이 되는 **인덱스 쌍**을 찾는 문제입니다.

---

## 1️⃣ 문제 접근

- Brute Force: 모든 쌍을 확인 → O(n²)
- 해시맵 활용: 지금까지 본 값과 인덱스를 저장해두고, `target - 현재값`이 이미 있는지 확인 → O(n)

---

## 2️⃣ 풀이 코드

```js
function twoSum(nums, target) {
  const seen = new Map();

  for (let i = 0; i < nums.length; i++) {
    const complement = target - nums[i];
    if (seen.has(complement)) return [seen.get(complement), i];
    seen.set(nums[i], i);
  }

  return [];
}

twoSum([2, 7, 11, 15], 9); // [0, 1]
```

---

## ✍️ 한 줄 정리

> **해시맵에 "이미 본 값"을 기록해두면 O(n²) 탐색을 O(n)으로 줄일 수 있다.**
