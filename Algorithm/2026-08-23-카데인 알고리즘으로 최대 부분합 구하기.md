# 📈 카데인 알고리즘으로 최대 부분합 구하기

배열에서 **연속된 부분 배열의 합 중 최댓값**을 O(n)에 구하는 대표적인 DP 기법입니다.

---

## 1️⃣ 문제 접근

- `현재까지의 최대합`을 유지하면서, 각 위치에서 "이전 합을 이어갈지, 새로 시작할지"를 선택
- 이전까지의 누적합이 음수라면 이어가는 것보다 **현재 값부터 새로 시작**하는 게 항상 유리

---

## 2️⃣ 풀이 코드

```js
function maxSubArray(nums) {
  let currentSum = nums[0];
  let maxSum = nums[0];

  for (let i = 1; i < nums.length; i++) {
    currentSum = Math.max(nums[i], currentSum + nums[i]);
    maxSum = Math.max(maxSum, currentSum);
  }

  return maxSum;
}

maxSubArray([-2, 1, -3, 4, -1, 2, 1, -5, 4]); // 6 ([4, -1, 2, 1])
```

---

## ✍️ 한 줄 정리

> **카데인 알고리즘은 "이어갈지 새로 시작할지"를 매 위치마다 O(1)에 판단해 최대 부분합을 O(n)에 구하는 기법이다.**
