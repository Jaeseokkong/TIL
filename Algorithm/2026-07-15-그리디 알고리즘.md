# 🪙 그리디 알고리즘 (Greedy Algorithm)

매 순간 **현재 상황에서 가장 최선(최적)이라고 판단되는 선택**을 반복해서
전체 문제의 해를 구하는 알고리즘 설계 기법입니다.

---

## 1️⃣ 핵심 아이디어

- 전체를 한 번에 고려하지 않고, **각 단계에서 지역적으로 최적인 선택**을 함
- 한 번 선택하면 번복하지 않음 (되돌아가지 않음)
- 항상 최적해를 보장하지는 않기 때문에, **탐욕적 선택 속성**과 **최적 부분 구조**가 성립하는 문제에서만 사용 가능

### 🔹 그리디가 통하는 조건

| 조건 | 설명 |
|------|------|
| 탐욕적 선택 속성 | 지역 최적 선택이 전역 최적해로 이어짐 |
| 최적 부분 구조 | 부분 문제의 최적해가 전체 문제의 최적해를 구성 |

👉 두 조건을 만족하지 않으면 DP(동적 계획법) 등 다른 접근이 필요합니다.

---

## 2️⃣ 대표 예시 - 거스름돈 문제

가장 큰 단위의 동전부터 최대한 많이 사용하는 방식으로 동전 개수를 최소화합니다.

```js
function minCoins(amount, coins) {
  const sorted = [...coins].sort((a, b) => b - a);
  let count = 0;

  for (const coin of sorted) {
    count += Math.floor(amount / coin);
    amount %= coin;
  }

  return count;
}

minCoins(1260, [500, 100, 50, 10]); // 6
```

⚠️ 동전 단위가 배수 관계가 아니면(예: [1, 3, 4]) 그리디가 최적해를 보장하지 못할 수 있습니다.

---

## ✍️ 한 줄 정리

> **그리디는 매 순간 최선의 선택을 반복하는 전략이며, 탐욕적 선택 속성과 최적 부분 구조가 성립할 때만 최적해를 보장한다.**
