# 🧵 Cluster 모듈과 멀티프로세싱

Node.js는 싱글 스레드로 동작하지만, `cluster` 모듈을 사용하면 **CPU 코어 수만큼 프로세스를 분기**해 처리량을 높일 수 있습니다.

---

## 1️⃣ 핵심 개념

- **Master(Primary) 프로세스** - Worker를 생성하고 관리
- **Worker 프로세스** - 실제 요청을 처리하는 독립된 Node.js 프로세스 (별도 메모리 공간)
- 들어오는 요청은 OS 또는 라운드 로빈 방식으로 Worker들에게 분산

---

## 2️⃣ 예시 코드

```js
const cluster = require("cluster");
const os = require("os");
const http = require("http");

if (cluster.isPrimary) {
  const cpuCount = os.cpus().length;
  for (let i = 0; i < cpuCount; i++) cluster.fork();

  cluster.on("exit", (worker) => {
    console.log(`Worker ${worker.process.pid} 종료 → 재기동`);
    cluster.fork();
  });
} else {
  http.createServer((req, res) => res.end("Hello")).listen(3000);
}
```

⚠️ Worker 간 메모리를 공유하지 않으므로, 전역 상태 공유가 필요하면 Redis 등 외부 저장소가 필요

---

## ✍️ 한 줄 정리

> **cluster 모듈은 CPU 코어 수만큼 독립된 워커 프로세스를 띄워 Node.js 애플리케이션의 처리량을 수평으로 확장한다.**
