# 🔐 Node.js 환경변수와 dotenv 관리

API 키, DB 접속 정보처럼 민감하거나 환경마다 달라지는 값은 코드에 하드코딩하지 않고 **환경변수**로 분리해 관리합니다.

---

## 1️⃣ dotenv 기본 사용법

```
# .env
DATABASE_URL=postgres://localhost:5432/mydb
API_KEY=secret-key
```

```js
require("dotenv").config();
console.log(process.env.DATABASE_URL);
```

- `.env` 파일의 값을 `process.env`에 로드해줌
- `.env`는 반드시 `.gitignore`에 추가해 저장소에 커밋되지 않도록 해야 함

---

## 2️⃣ 환경별 파일 분리

```
.env.development
.env.production
.env.test
```

```js
require("dotenv").config({ path: `.env.${process.env.NODE_ENV}` });
```

- 개발/운영/테스트 환경마다 다른 값을 사용할 때, 파일을 분리하고 `NODE_ENV`로 선택해 로드
