# 🌊 Node.js Stream 기본 개념

Stream은 데이터를 **한 번에 메모리에 모두 올리지 않고, 조각(chunk) 단위로 순차 처리**하는 방식입니다.

---

## 1️⃣ 4가지 스트림 종류

| 종류 | 설명 |
|------|------|
| Readable | 데이터를 읽어오는 스트림 (예: 파일 읽기) |
| Writable | 데이터를 써주는 스트림 (예: 파일 쓰기) |
| Duplex | 읽기/쓰기 모두 가능 (예: TCP 소켓) |
| Transform | 읽으면서 데이터를 변형해 전달 (예: 압축) |

---

## 2️⃣ 예시 코드 - 대용량 파일 복사

```js
const fs = require("fs");

const readStream = fs.createReadStream("input.txt");
const writeStream = fs.createWriteStream("output.txt");

readStream.pipe(writeStream);
```

- 전체 파일을 메모리에 올리지 않고 chunk 단위로 읽고 쓰기 때문에 **메모리 사용량이 일정**하게 유지됨
- `pipe()`는 내부적으로 backpressure(쓰기 속도가 느릴 때 읽기를 잠시 멈추는 것)까지 처리해줌

---

## 3️⃣ 언제 Stream을 써야 할까

- 대용량 파일 처리, 실시간 데이터 전송(영상 스트리밍), HTTP 응답 스트리밍 등
- 작은 데이터를 다룰 때는 오히려 복잡도만 높아지므로 일반 읽기/쓰기 API로 충분

---

## ✍️ 한 줄 정리

> **Stream은 데이터를 chunk 단위로 순차 처리해, 대용량 데이터를 다룰 때도 메모리 사용량을 일정하게 유지해준다.**
