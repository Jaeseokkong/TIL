# ⛓️ Express 미들웨어 체인 이해하기

Express의 핵심은 요청이 여러 **미들웨어 함수를 순서대로 거쳐가는** 구조입니다.

---

## 1️⃣ 기본 구조

```js
app.use((req, res, next) => {
  console.log("1번 미들웨어");
  next(); // 다음 미들웨어로 넘김
});

app.use((req, res, next) => {
  console.log("2번 미들웨어");
  next();
});

app.get("/", (req, res) => {
  res.send("응답 완료");
});
```

- `next()`를 호출하지 않으면 요청이 다음 단계로 넘어가지 않고 그대로 멈춤
