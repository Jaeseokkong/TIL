# ⚡ Next.js Server Actions

Server Actions는 클라이언트에서 **별도의 API 라우트 없이 서버 함수를 직접 호출**할 수 있게 해주는 App Router 기능입니다.

---

## 1️⃣ 기본 사용법

```tsx
// app/actions.ts
"use server";

export async function createPost(formData: FormData) {
  const title = formData.get("title");
  await db.post.create({ data: { title } });
}
```

```tsx
// app/new/page.tsx
import { createPost } from "../actions";

export default function NewPostPage() {
  return (
    <form action={createPost}>
      <input name="title" />
      <button type="submit">등록</button>
    </form>
  );
}
```

- `"use server"` 지시어가 붙은 함수는 클라이언트 번들에 포함되지 않고, 호출 시 서버에서 실행됨

---

## 2️⃣ 클라이언트 컴포넌트에서 호출하기

```tsx
"use client";
import { createPost } from "../actions";

export function PostForm() {
  return (
    <form action={async (formData) => {
      await createPost(formData);
      alert("등록 완료");
    }}>
      <input name="title" />
      <button type="submit">등록</button>
    </form>
  );
}
```

- 폼뿐 아니라 버튼 클릭 등 일반 이벤트 핸들러 안에서도 직접 호출 가능

---

## 3️⃣ API Route와 비교

- API Route처럼 별도 엔드포인트를 만들고 fetch로 호출할 필요 없이, 함수 호출처럼 서버 로직을 실행
- 다만 세밀한 HTTP 상태 코드/헤더 제어가 필요하면 여전히 Route Handler가 적합

---

## ✍️ 한 줄 정리

> **Server Actions는 API 라우트 없이 폼/이벤트에서 서버 함수를 직접 호출할 수 있게 해주며, 세밀한 HTTP 제어가 필요하면 여전히 Route Handler를 쓰는 것이 낫다.**
