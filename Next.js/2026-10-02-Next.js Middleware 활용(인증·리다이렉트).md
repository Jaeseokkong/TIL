# 🚦 Next.js Middleware 활용 (인증·리다이렉트)

Middleware는 요청이 페이지/API에 도달하기 **전에** 실행되어, 인증 체크나 리다이렉트 같은 공통 로직을 처리할 수 있습니다.

---

## 1️⃣ 기본 구조

```ts
// middleware.ts (프로젝트 루트)
import { NextResponse } from "next/server";
import type { NextRequest } from "next/server";

export function middleware(request: NextRequest) {
  return NextResponse.next();
}

export const config = {
  matcher: ["/dashboard/:path*"], // 이 경로에만 미들웨어 적용
};
```

- Edge Runtime에서 실행되어 일반 Node.js API를 모두 쓸 수는 없지만, 그만큼 빠르게 요청 초기에 개입 가능
