# 🔗 프로토타입 체인 (Prototype Chain)

JS는 클래스 기반이 아닌 **프로토타입 기반 상속** 언어입니다.
객체는 자신에게 없는 프로퍼티를 찾을 때 `[[Prototype]]`을 따라 올라가며 탐색합니다.

---

## 1️⃣ 핵심 개념

- 모든 객체는 내부 슬롯 `[[Prototype]]`을 가짐 (`__proto__`로 접근 가능, 비표준이지만 널리 지원)
- 프로퍼티를 찾을 때 자신 → 프로토타입 → 프로토타입의 프로토타입 순으로 탐색
- 체인의 끝은 `Object.prototype`이며, 그 다음은 `null`

---

## 2️⃣ 예시 코드

```js
function Animal(name) {
  this.name = name;
}

Animal.prototype.speak = function () {
  console.log(`${this.name}가 소리를 냅니다.`);
};

const dog = new Animal("멍멍이");
dog.speak(); // "멍멍이가 소리를 냅니다."

console.log(dog.hasOwnProperty("speak"));           // false
console.log(dog.__proto__ === Animal.prototype);    // true
```

- `dog` 자신은 `speak`를 갖고 있지 않지만, 프로토타입 체인을 통해 `Animal.prototype.speak`를 찾아 호출
