# 📦 구조 분해 할당과 스프레드 연산자

배열/객체의 값을 꺼내거나 합칠 때 사용하는 ES6 문법을 정리합니다.

---

## 1️⃣ 구조 분해 할당 (Destructuring)

```js
const user = { name: "재석", age: 30 };
const { name, age: userAge = 20 } = user;
// name = "재석", userAge = 30

const [first, , third] = [1, 2, 3];
// first = 1, third = 3
```

- 객체는 **키 이름**으로, 배열은 **순서(인덱스)**로 매칭
- 기본값(`=`)과 별칭(`:`) 동시 사용 가능

---

## 2️⃣ 중첩 구조 분해 & 함수 매개변수 활용

```js
const { user: { name, address: { city } } } = response;

function printUser({ name, age = 0 }) {
  console.log(`${name} (${age})`);
}
```

- 함수 매개변수에서 바로 구조 분해하면 불필요한 중간 변수를 줄일 수 있음

---

## 3️⃣ 스프레드 연산자 (Spread)

```js
const arr1 = [1, 2];
const arr2 = [...arr1, 3, 4]; // [1, 2, 3, 4]

const obj1 = { a: 1, b: 2 };
const obj2 = { ...obj1, c: 3 }; // { a: 1, b: 2, c: 3 }

function sum(...nums) {   // Rest 파라미터
  return nums.reduce((a, b) => a + b, 0);
}
sum(1, 2, 3); // 6
```

⚠️ 스프레드는 **얕은 복사**이므로, 중첩 객체/배열은 참조를 그대로 공유합니다.

---

## ✍️ 한 줄 정리

> **구조 분해는 값을 꺼내는 문법, 스프레드는 값을 펼쳐 합치는 문법이며 둘 다 얕은 복사 수준으로 동작한다.**
