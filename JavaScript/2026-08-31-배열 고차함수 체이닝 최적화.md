# 🔗 배열 고차함수(map/filter/reduce) 체이닝 최적화

`map`, `filter`, `reduce`를 이어붙이면 가독성은 좋지만, **배열을 여러 번 순회**하게 되는 비용도 함께 생각해야 합니다.

---

## 1️⃣ 체이닝의 비용

```js
const result = items
  .filter((i) => i.active)
  .map((i) => i.price)
  .reduce((sum, price) => sum + price, 0);
```

- `filter`, `map`, `reduce`가 각각 배열을 한 번씩 순회 → 총 3번 순회 (O(3n))
- 데이터가 작다면 문제없지만, 대량 데이터에서는 순회 횟수를 줄이는 게 유리
