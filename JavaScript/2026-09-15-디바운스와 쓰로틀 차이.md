# ⏱️ 디바운스(Debounce)와 쓰로틀(Throttle) 차이

둘 다 짧은 시간에 반복 호출되는 이벤트(스크롤, 입력 등)를 제어하는 기법이지만, **동작 방식이 다릅니다**.

---

## 1️⃣ Debounce - 마지막 호출만 실행

```js
function debounce(fn, delay) {
  let timer;
  return (...args) => {
    clearTimeout(timer);
    timer = setTimeout(() => fn(...args), delay);
  };
}
```

- 이벤트가 연속으로 발생하는 동안은 실행을 계속 미루다가, **마지막 호출 이후 delay가 지나야** 실행
- 검색어 자동완성처럼 "입력이 멈췄을 때만" 요청을 보내고 싶을 때 사용

---

## 2️⃣ Throttle - 일정 간격으로 실행

```js
function throttle(fn, interval) {
  let lastTime = 0;
  return (...args) => {
    const now = Date.now();
    if (now - lastTime >= interval) {
      lastTime = now;
      fn(...args);
    }
  };
}
```

- 이벤트가 아무리 자주 발생해도 **일정 간격마다 한 번씩만** 실행
- 스크롤 위치 감지, 무한 스크롤처럼 "계속 반응은 하되 너무 자주는 안 되는" 상황에 사용

---

## 3️⃣ 선택 기준

| 상황 | 선택 |
|------|------|
| 입력이 끝난 뒤 한 번만 처리하고 싶을 때 (검색, 자동 저장) | Debounce |
| 이벤트가 계속 발생하는 동안에도 주기적으로 반응해야 할 때 (스크롤, 리사이즈) | Throttle |

---

## ✍️ 한 줄 정리

> **디바운스는 마지막 호출 이후 일정 시간이 지나야 실행되고, 쓰로틀은 이벤트가 계속 발생해도 일정 간격마다 한 번씩 실행된다.**
