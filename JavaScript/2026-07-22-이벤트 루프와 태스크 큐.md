# 🔁 이벤트 루프와 태스크 큐

JS는 싱글 스레드지만, 이벤트 루프 덕분에 **비동기 작업을 논블로킹으로 처리**할 수 있습니다.

---

## 1️⃣ 구성 요소

- **Call Stack** - 현재 실행 중인 함수들이 쌓이는 곳
- **Web APIs** - setTimeout, fetch 등 브라우저/Node가 제공하는 비동기 기능 수행
- **Task Queue(Macrotask Queue)** - setTimeout, setInterval 콜백이 대기
- **Microtask Queue** - Promise.then, queueMicrotask 콜백이 대기

### 🔹 실행 우선순위

콜 스택이 빌 때마다 **Microtask Queue를 모두 비운 뒤**, Task Queue에서 하나를 꺼내 실행합니다.
