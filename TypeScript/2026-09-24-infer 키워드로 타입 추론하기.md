# 🕵️ infer 키워드로 타입 추론하기

`infer`는 조건부 타입 안에서 **타입의 특정 부분을 변수처럼 뽑아내는** 키워드입니다.

---

## 1️⃣ 기본 문법

```ts
type ElementType<T> = T extends (infer U)[] ? U : never;

type A = ElementType<string[]>; // string
type B = ElementType<number[]>; // number
```

- `T extends (infer U)[]`는 "T가 배열이라면, 그 요소 타입을 U라는 이름으로 뽑아내겠다"는 뜻
- 조건이 거짓이면 `never` 등 원하는 타입으로 대체

---

## 2️⃣ 함수 반환 타입 추출하기

```ts
type ReturnTypeOf<T> = T extends (...args: any[]) => infer R ? R : never;

function getUser() {
  return { id: 1, name: "재석" };
}

type User = ReturnTypeOf<typeof getUser>; // { id: number; name: string }
```

- 실제로 TypeScript 내장 유틸리티 `ReturnType<T>`도 이와 동일한 원리로 구현되어 있음
