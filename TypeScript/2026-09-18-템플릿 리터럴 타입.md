# 🧵 TypeScript 템플릿 리터럴 타입

문자열 리터럴 타입을 **템플릿 문자열처럼 조합**해서 더 구체적인 문자열 타입을 만드는 기능입니다.

---

## 1️⃣ 기본 문법

```ts
type Direction = "top" | "bottom" | "left" | "right";
type Margin = `margin-${Direction}`;
// "margin-top" | "margin-bottom" | "margin-left" | "margin-right"
```

- 여러 유니언 타입을 조합하면 **모든 경우의 수가 곱해져서** 생성됨

---

## 2️⃣ 이벤트 핸들러 이름 타입 만들기

```ts
type EventName = "click" | "change" | "submit";
type HandlerName = `on${Capitalize<EventName>}`;
// "onClick" | "onChange" | "onSubmit"
```

- `Capitalize`, `Uncapitalize`, `Uppercase`, `Lowercase` 같은 내장 유틸리티 타입과 조합해서 사용

---

## 3️⃣ 실전 예시 - API 경로 타입 제한

```ts
type ResourceId = number | string;
type ApiPath = `/users/${ResourceId}` | `/posts/${ResourceId}`;

function request(path: ApiPath) { /* ... */ }

request("/users/1");    // ✅
request("/comments/1"); // ❌ 컴파일 에러
```

- 문자열이지만 **정해진 패턴만 허용**하도록 강제할 수 있어, 오타나 잘못된 경로 사용을 컴파일 타임에 잡아냄

---

## 4️⃣ 주의할 점

- 유니언 조합이 많아지면 타입 조합 수가 기하급수적으로 늘어나 **컴파일 속도가 느려질 수 있음**
- 너무 세밀한 패턴 제한보다는, 실제로 오류를 자주 유발하는 영역(이벤트 이름, 경로 등)에 선택적으로 적용하는 것이 좋음

---

## ✍️ 한 줄 정리

> **템플릿 리터럴 타입은 문자열 리터럴을 조합해 더 구체적인 문자열 패턴을 컴파일 타임에 강제할 수 있게 해준다.**
