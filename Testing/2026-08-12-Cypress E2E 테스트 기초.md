# 🌲 Cypress E2E 테스트 기초

Cypress는 브라우저에서 실제 사용자 흐름을 시뮬레이션하는 **E2E(End-to-End) 테스트 도구**입니다.

---

## 1️⃣ 특징

- 브라우저 안에서 직접 실행되어 실제 DOM에 접근 (디버깅이 쉬움)
- 자동 대기(auto-wait) - 요소가 나타날 때까지 자동으로 재시도
- 타임 트래블 - 각 단계의 스냅샷을 확인 가능

---

## 2️⃣ 예시 코드

```js
describe("로그인", () => {
  it("올바른 정보로 로그인하면 대시보드로 이동한다", () => {
    cy.visit("/login");
    cy.get('[data-testid="email"]').type("test@example.com");
    cy.get('[data-testid="password"]').type("password123");
    cy.get('[data-testid="submit"]').click();

    cy.url().should("include", "/dashboard");
    cy.contains("환영합니다").should("be.visible");
  });
});
```

- `data-testid`처럼 스타일과 무관한 selector를 사용하면 마크업 변경에도 테스트가 깨지지 않음

---

## 3️⃣ 네트워크 요청 제어 - cy.intercept

```js
cy.intercept("GET", "/api/user", { fixture: "user.json" }).as("getUser");
cy.visit("/profile");
cy.wait("@getUser");
```

- 실제 API 대신 고정된 응답(fixture)을 사용하면 테스트가 외부 상태에 흔들리지 않음

---

## ✍️ 한 줄 정리

> **Cypress는 실제 브라우저에서 사용자 흐름을 그대로 재현하며 자동 대기 기능으로 비동기 UI 테스트를 안정적으로 만든다.**
