# 📐 clamp()로 반응형 타이포그래피

미디어 쿼리로 폰트 크기를 여러 구간으로 나눠 지정하는 대신, `clamp()` 함수 하나로 **최소~최대 사이를 화면 크기에 맞춰 부드럽게** 보간할 수 있습니다.

---

## 1️⃣ 기본 문법

```css
font-size: clamp(최솟값, 선호값, 최댓값);
```

```css
h1 {
  font-size: clamp(1.5rem, 4vw, 3rem);
}
```

- 화면이 작으면 `1.5rem`, 크면 `3rem`, 그 사이는 `4vw`를 기준으로 부드럽게 변함
- 미디어 쿼리 여러 개 없이 **한 줄로 반응형 폰트 크기**를 표현 가능

---

## 2️⃣ vw만 쓰면 안 되는 이유

```css
/* ❌ 화면이 아주 작거나 크면 글씨가 너무 작거나 커짐 */
font-size: 4vw;

/* ✅ 최소/최대 한계를 clamp로 고정 */
font-size: clamp(1.5rem, 4vw, 3rem);
```

- `vw` 단위만 쓰면 뷰포트 크기에 선형으로 비례해 **극단적인 화면 크기에서 가독성이 깨질 수 있음**
- `clamp`의 최소/최대값이 그 한계를 잡아주는 안전장치 역할

---

## 3️⃣ 간격(spacing)에도 활용

```css
.section {
  padding-block: clamp(16px, 5vw, 64px);
}
```

- 폰트 크기뿐 아니라 여백·간격에도 동일한 방식으로 활용 가능

---

## ✍️ 한 줄 정리

> **clamp(min, 선호값, max)는 미디어 쿼리 없이도 화면 크기에 따라 값이 부드럽게 변하면서도 최소/최대 한계를 보장해주는 반응형 CSS 함수다.**
