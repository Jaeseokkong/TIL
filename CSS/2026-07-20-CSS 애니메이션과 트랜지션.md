# 🎞️ CSS 애니메이션과 트랜지션

CSS만으로 상태 변화에 움직임을 부여하는 두 가지 방법, **transition**과 **animation**의 차이를 정리합니다.

---

## 1️⃣ Transition vs Animation

| 구분 | transition | animation |
|------|-----------|-----------|
| 트리거 | 상태 변화(hover, class 변경 등) 필요 | 자동 실행 가능 |
| 반복 | 불가능 | `animation-iteration-count`로 반복 가능 |
| 중간 단계 | 시작~끝 값만 지정 | `@keyframes`로 여러 단계 지정 가능 |

👉 단순한 상태 전환은 transition, 복잡하고 반복적인 움직임은 animation이 적합합니다.
