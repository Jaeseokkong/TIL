# 🧱 CSS Grid 실전 레이아웃 패턴

Grid는 행과 열을 동시에 다루는 2차원 레이아웃 시스템으로, 복잡한 페이지 레이아웃을 간단하게 구성할 수 있습니다.

---

## 1️⃣ 기본 문법

```css
.layout {
  display: grid;
  grid-template-columns: 240px 1fr;
  grid-template-rows: 60px 1fr;
  grid-template-areas:
    "sidebar header"
    "sidebar content";
}

.sidebar { grid-area: sidebar; }
.header  { grid-area: header; }
.content { grid-area: content; }
```

- `grid-template-areas`로 레이아웃을 이름으로 시각화하듯 정의 가능

---

## 2️⃣ 반응형 카드 그리드 - auto-fit / minmax

```css
.cards {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));
  gap: 16px;
}
```

- 화면 너비에 따라 카드 개수가 자동으로 조절되며, 미디어 쿼리 없이도 반응형 그리드 구현 가능
- `auto-fill`은 빈 트랙도 유지하고, `auto-fit`은 빈 트랙을 남은 열에 채워 넓힘
