# 📱 반응형 디자인과 미디어 쿼리

하나의 마크업으로 다양한 화면 크기에 대응하기 위한 CSS 미디어 쿼리 활용법을 정리합니다.

---

## 1️⃣ Mobile First vs Desktop First

| 전략 | 설명 |
|------|------|
| Mobile First | 기본 스타일을 모바일 기준으로 작성 후 `min-width`로 확장 |
| Desktop First | 기본 스타일을 데스크탑 기준으로 작성 후 `max-width`로 축소 |

👉 최근에는 모바일 트래픽 비중이 높아 **Mobile First**가 권장됨
