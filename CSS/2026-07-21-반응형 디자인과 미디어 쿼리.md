# 📱 반응형 디자인과 미디어 쿼리

하나의 마크업으로 다양한 화면 크기에 대응하기 위한 CSS 미디어 쿼리 활용법을 정리합니다.

---

## 1️⃣ Mobile First vs Desktop First

| 전략 | 설명 |
|------|------|
| Mobile First | 기본 스타일을 모바일 기준으로 작성 후 `min-width`로 확장 |
| Desktop First | 기본 스타일을 데스크탑 기준으로 작성 후 `max-width`로 축소 |

👉 최근에는 모바일 트래픽 비중이 높아 **Mobile First**가 권장됨

---

## 2️⃣ 미디어 쿼리의 한계와 컨테이너 쿼리

미디어 쿼리는 **뷰포트 크기**만 기준으로 하기 때문에, 같은 컴포넌트가 여러 레이아웃에 재사용될 때 대응이 어렵습니다.

```css
@container (min-width: 400px) {
  .card { display: flex; }
}
```

- `container-type: inline-size`를 부모에 지정하면 컨테이너 쿼리를 사용할 수 있음

---

## 3️⃣ 예시 코드

```css
/* Mobile First */
.container {
  padding: 12px;
}

@media (min-width: 768px) {
  .container {
    padding: 24px;
    display: flex;
  }
}

@media (min-width: 1024px) {
  .container {
    max-width: 1200px;
    margin: 0 auto;
  }
}
```

- 뷰포트 메타 태그(`<meta name="viewport" content="width=device-width, initial-scale=1">`)가 없으면 미디어 쿼리가 의도대로 동작하지 않을 수 있음

---

## ✍️ 한 줄 정리

> **미디어 쿼리는 화면 너비 구간별로 스타일을 분기하는 도구이며, 모바일 기준으로 작성 후 넓은 화면을 위해 확장하는 것이 일반적이다.**
