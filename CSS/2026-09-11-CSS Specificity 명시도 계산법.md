# 🎯 CSS 명시도(Specificity) 계산법

여러 선택자가 같은 요소에 다른 스타일을 지정할 때, **어떤 규칙이 최종 적용될지**를 결정하는 우선순위 계산 방식입니다.

---

## 1️⃣ 명시도 점수 구성

| 선택자 종류 | 점수 |
|-------------|------|
| 인라인 스타일 | 1000 |
| id 선택자 (`#id`) | 100 |
| 클래스/속성/가상클래스 (`.class`, `[type]`, `:hover`) | 10 |
| 태그/가상요소 (`div`, `::before`) | 1 |

- 점수가 높은 규칙이 이김, 점수가 같으면 **나중에 선언된 규칙**이 이김
