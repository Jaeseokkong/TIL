# 🎯 CSS 명시도(Specificity) 계산법

여러 선택자가 같은 요소에 다른 스타일을 지정할 때, **어떤 규칙이 최종 적용될지**를 결정하는 우선순위 계산 방식입니다.

---

## 1️⃣ 명시도 점수 구성

| 선택자 종류 | 점수 |
|-------------|------|
| 인라인 스타일 | 1000 |
| id 선택자 (`#id`) | 100 |
| 클래스/속성/가상클래스 (`.class`, `[type]`, `:hover`) | 10 |
| 태그/가상요소 (`div`, `::before`) | 1 |

- 점수가 높은 규칙이 이김, 점수가 같으면 **나중에 선언된 규칙**이 이김

---

## 2️⃣ 계산 예시

```css
div.card p { color: blue; }        /* 0-1-2 → 태그2 + 클래스1 */
#sidebar p { color: red; }         /* 0-1-1 → id1 + 태그1 */
```

- `#sidebar p`가 `div.card p`보다 명시도가 높아 `color: red`가 적용됨
- `!important`는 이 계산을 모두 무시하고 최우선 적용되므로, 남용하면 이후 디버깅이 매우 어려워짐
