# 🗄️ 브라우저 캐싱 전략 (Cache-Control 헤더)

정적 리소스를 재방문 시 네트워크 요청 없이 재사용하도록, 서버가 응답 헤더로 **캐싱 정책**을 지정할 수 있습니다.

---

## 1️⃣ 주요 Cache-Control 지시어

| 지시어 | 의미 |
|--------|------|
| `max-age=3600` | 3600초 동안 재요청 없이 캐시 사용 |
| `no-cache` | 캐시는 저장하되, 매번 서버에 유효성 재검증 요청 |
| `no-store` | 아예 캐시하지 않음 (민감한 데이터에 사용) |
| `immutable` | 내용이 절대 바뀌지 않음을 명시 (재검증 요청도 생략) |
