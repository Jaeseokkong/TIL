# 🔑 React key prop 최적화

리스트를 렌더링할 때 사용하는 `key`는 React가 **각 항목을 식별해 재조정(reconciliation)** 하는 데 사용하는 중요한 힌트입니다.

---

## 1️⃣ key가 하는 일

- React는 이전 렌더와 이후 렌더의 자식 엘리먼트를 `key`로 비교
- 같은 key를 가진 엘리먼트는 재사용(상태 유지), key가 사라지면 언마운트, 새로 생기면 마운트
- key가 없거나 부적절하면 불필요한 언마운트/마운트가 발생해 상태가 초기화되거나 성능이 저하될 수 있음

---

## 2️⃣ index를 key로 쓰면 안 되는 경우

```jsx
// ❌ 리스트 순서가 바뀌거나 항목이 삭제되면 문제 발생
{items.map((item, index) => <Item key={index} {...item} />)}

// ✅ 데이터 고유의 id를 key로 사용
{items.map((item) => <Item key={item.id} {...item} />)}
```

- 항목을 삭제/삽입/정렬하면 index가 밀리면서 **엉뚱한 항목이 재사용**되어 input 값이나 애니메이션 상태가 꼬일 수 있음

---

## 3️⃣ index를 써도 괜찮은 경우

- 리스트가 **정적**이고, 추가·삭제·재정렬이 절대 없는 경우
- 항목에 애초에 고유 id가 없고, 렌더링 후 상태를 갖지 않는 단순 표시용 리스트인 경우

---

## ✍️ 한 줄 정리

> **key는 재조정 시 항목을 식별하는 힌트이며, 리스트가 변할 수 있다면 index 대신 데이터 고유의 id를 key로 사용해야 한다.**
